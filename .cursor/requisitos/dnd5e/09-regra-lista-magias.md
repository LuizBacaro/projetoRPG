### 1.2 Recuperação de Slots

- **Repouso longo**: recupera todos os slots gastos para a maioria das classes (Bardo, Clérigo, Druida, Feiticeiro, Mago, Paladino, Patrulheiro, Ladino Arcano, Guerreiro EK).
- **Repouso curto**: Bruxos recuperam todos os slots de magia.
- **Pontos de Feitiçaria**: Feiticeiros podem converter Pontos de Feitiçaria em slots (e vice-versa) como ação bônus.
- **Recuperação Arcana**: Magos podem recuperar um total de slots por nível igual ao seu nível de mago (arredondado para baixo) após um repouso curto, uma vez por dia.

### 1.3 Upcasting (Lançamento com Slot Superior)

- Uma magia pode ser lançada usando um slot de nível superior ao seu nível base.
- Efeitos adicionais são especificados na descrição da magia (ex.: +1d6 de dano por nível de slot acima do base, ou mais alvos).
- O nível do slot usado determina os efeitos; o nível original da magia não se altera.

### 1.4 Truques (Nível 0)

- Não consomem slots de magia.
- Podem ser lançados à vontade, sem limite.
- O dano de truques escala com o nível total do personagem (não apenas com o nível de conjurador):
  - Nível 1–4: como descrito
  - Nível 5–10: 2 dados de dano
  - Nível 11–16: 3 dados de dano
  - Nível 17–20: 4 dados de dano

## 2. COMPONENTES DE MAGIA

### 2.1 Verbal (V)

- O conjurador deve falar em voz clara e audível.
- Impedido por: condição de *silenciado*, área de *Campo de Silêncio*, estar submerso sem capacidade de respirar, ou qualquer efeito que impeça a fala.
- Criaturas amordaçadas ou sob efeito de *Sono* não podem lançar magias com componente V.

### 2.2 Somático (S)

- O conjurador deve ter pelo menos uma mão livre para realizar gestos precisos.
- Impedido por: estar algemado, ambas as mãos segurando objetos (exceto se usar um foco arcano em uma mão e a outra estiver livre, ou com o talento *Conjurador de Guerra* que permite gestos com mãos ocupadas).
- Se a magia possui componentes M e S, a mesma mão pode segurar o foco e realizar os gestos.

### 2.3 Material (M)

- Itens específicos (ex.: um pedaço de guano de morcego e enxofre para *Bola de Fogo*).
- Podem ser substituídos por um **foco arcano** (varinha, cetro, bastão), **símbolo sagrado** (para clérigos e paladinos) ou **bolsa de componentes** (component pouch).
- Componentes com custo monetário (em ouro) ou consumidos pela magia **não** podem ser substituídos pelo foco – devem estar fisicamente presentes.
- Componentes consumidos são gastos e removidos do inventário.

## 4. ALCANCE DE MAGIA

- **Toque (Touch)**: O conjurador deve estar adjacente ao alvo (alcance natural de 1,5m/5 pés).
- **Pessoal (Self)**: A magia afeta apenas o próprio conjurador.
- **Distância em pés**: Exemplos: 30 pés (9m), 60 pés (18m), 120 pés (36m), 1 milha, etc.
- **Visão (Sight)**: Qualquer alvo que o conjurador possa ver claramente, sem obstrução total.
- **Ilimitado (Unlimited)**: Sem limite máximo de distância. Geralmente exige que o conjurador conheça o alvo (ex.: *Enviar Mensagem*, *Localizar Criatura*).

---

## 5. DURAÇÃO E CONCENTRAÇÃO

### 5.1 Tipos de Duração

- **Instantânea**: O efeito ocorre e termina imediatamente no mesmo turno. Não pode ser dissipado.
- **Minutos/Horas/Dias**: Ex.: *Invisibilidade* dura 1 hora, *Sono* dura 1 minuto.
- **Até ser dissipada**: A magia permanece ativa até que *Dissipar Magia* seja usada com sucesso ou a magia seja anulada de outra forma.
- **Especial**: Condições específicas (ex.: *Bênção* dura concentração até 1 hora, mas pode terminar antes).

### 5.2 Concentração

- Um conjurador pode manter no máximo **uma** magia com concentração por vez.
- **Quebra de concentração** ocorre por:
  - Sofrer dano (teste de Constituição, CD = 10 ou metade do dano sofrido, o que for maior).
  - Ficar **incapacitado** ou **morto**.
  - Lançar outra magia que exija concentração.
  - Ser alvo de *Tempestade Mental* ou efeitos similares que forçam teste.
- **Teste de Concentração**: Salvaguarda de Constituição, CD conforme acima. Fracasso = concentração perdida.

---

## 6. TESTES DE RESISTÊNCIA

**Fórmula da CD (Classe de Dificuldade) para salvaguardas:**

`CD = 8 + modificador de habilidade de conjuração + bônus de proficiência`

- Tipos de salvaguarda: Força (STR), Destreza (DEX), Constituição (CON), Inteligência (INT), Sabedoria (WIS), Carisma (CHA).
- **Efeito do sucesso** varia por magia: metade do dano, nenhum dano, negação total do efeito, etc.

---

## 7. TESTES DE ATAQUE DE MAGIA

**Fórmula do bônus de ataque mágico:**

`Bônus = modificador de habilidade de conjuração + bônus de proficiência`

**Rolagem:** `d20 + bônus` vs **CA (Classe de Armadura)** do alvo.

- Ataques de magia podem ser à distância (ranged spell attack) ou corpo a corpo (melee spell attack).

## 10. REGRAS ESPECIAIS

### 10.1 Lançamento em Armadura

- O conjurador deve ter **proficiência** com a armadura que está vestindo.
- Se não tiver proficiência, **todas as magias lançadas falham** automaticamente (não apenas as com componente S).
- Exceção: Clérigos e Paladinos são proficientes com armaduras pesadas; Druidas recusam metal, etc.

### 10.2 Magia Ritual

- A magia deve possuir a tag **Ritual**.
- O conjurador deve ter a feature **Conjuração Ritualística** (disponível para Magos, Clérigos, Druidas, Bardos, Bruxos (com talento) e alguns outros).
- Ao lançar como ritual, o tempo de conjuração aumenta em **10 minutos** e **nenhum slot de magia é consumido**.

### 10.3 Magias Conhecidas vs Preparadas

- **Conhecidas (Known)**: O personagem aprende um número fixo de magias e não pode trocá-las livremente (Bardo, Feiticeiro, Bruxo, Patrulheiro, Ladino Arcano, Guerreiro EK). Ao subir de nível, pode substituir uma magia conhecida por outra.
- **Preparadas (Prepared)**: O personagem tem acesso a uma lista maior e escolhe diariamente quais magias preparar (Clérigo, Druida, Mago, Paladino). A preparação geralmente acontece após um repouso longo.

### 10.4 Regra de Multicast (Ação Bônus)

- Se um personagem lança qualquer magia como **ação bônus**, ele só pode lançar **truques** como ação padrão no mesmo turno.
- Ativar o efeito de uma magia já existente (ex.: *Chicote de Espinhos* que permite repetir o ataque com ação) não ativa essa restrição.

# PROMPT PARA CURSOR

Você é um desenvolvedor sênior de jogos. Preciso implementar o sistema de magias de D&D 5e em um jogo. O sistema deve seguir as regras descritas neste documento de requisitos. Use TypeScript e arquitetura orientada a dados.

## Arquitetura de Dados

Crie interfaces TypeScript para:

```typescript
interface Spell {
  id: string;
  name: string;
  level: number; // 0-9
  castingTime: {
    value: number;
    ritual: boolean;
  };
  range: {
    value?: number; // em pés
  };
  components: {
    verbal: boolean;
    somatic: boolean;
    material: string | null;
    materialConsumed: boolean;
    materialCost: number; // em moeda de ouro
  };
  duration: {
    value?: number;
    instantaneous: boolean;
    untilDispelled: boolean;
  };
  concentration: boolean;
  description: string;
  damageInfo?: {
    dice: string; // ex: '1d8', '3d6'
    scaling: 'none' | 'per_slot_level' | 'per_character_level';
  };
  saveInfo?: {
    effect: 'half' | 'none' | 'negate';
  };
  attackInfo?: {
    type: 'melee_spell' | 'ranged_spell';
  };
  areaOfEffect?: {
    size: number; // em pés
  };
  higherLevelDescription?: string;
}

interface SpellSlots {
  [spellLevel: number]: number; // nível 1-9, valor é qtd slots
}

interface ConcentrationInfo {
  activeSpell: Spell | null;
  startTurn: number;
}
```

## Gerenciadores Necessários

### 1. SpellSlotsManager
- `canCast(spellLevel: number): boolean`
- `useSlot(spellLevel: number): void`
- `recoverSlots(restType: 'short' | 'long'): void`
- `getAvailableSlots(): SpellSlots`
- `upcastToSlot(spellLevel: number, slotLevel: number): void` – valida slot nível >= spellLevel

### 2. ConcentrationManager
- `startConcentration(spell: Spell, currentTurn: number): void`
- `breakConcentration(): void`
- `isConcentrating(): boolean`
- `onDamage(damageAmount: number, caster: Character): boolean` (retorna se concentração foi mantida)

### 3. SpellCastingEngine
- `castSpell(spell: Spell, caster: Character, target: Character | Point): CastResult`
  - Validações: conhece/prepara, componentes, slots, concentração, proficiência armadura, silêncio, mãos livres.
  - Aplica saves, ataques, dano, cura, concentração.
  - Retorna resultado completo.

### 4. Character (integração)
- `spellSlotsManager: SpellSlotsManager`
- `concentrationManager: ConcentrationManager`
- `spellcastingAbility: string` (ex: 'intelligence')
- `proficiencyBonus: number`
- `isSilenced: boolean`
- `hasFreeHand: boolean`
- `isProficientWithArmor: boolean`
- `knownSpells: Spell[]` (se classe conhecida) ou `preparedSpells: Spell[]` (se preparada) ou `spellList: Spell[]` (para classes que preparam a partir de uma lista completa)

## Fluxo de Lançamento (passo a passo)

1. Verificar se o conjurador **conhece** ou **preparou** a magia.
2. Verificar **componentes**:
   - Se V: `caster.isSilenced` deve ser false.
   - Se S: `caster.hasFreeHand` deve ser true (ou talento Conjurador de Guerra).
   - Se M com custo ou consumido: verificar inventário e remover.
3. Verificar **slot** (se não é truque): `caster.spellSlotsManager.canCast(spell.level)`.
4. Verificar **proficiência em armadura**: se não for proficiente, magia falha automaticamente.
5. Se já estiver **concentrando**: chamar `caster.concentrationManager.breakConcentration()`.
6. Calcular **CD** ou **bônus de ataque**:
   - CD = 8 + caster.spellcastingAbilityModifier + caster.proficiencyBonus
   - Ataque = d20 + caster.spellcastingAbilityModifier + caster.proficiencyBonus
7. Executar **salvaguarda** (se `spell.saveInfo`) ou **ataque** (se `spell.attackInfo`).
8. Se acerto ou falha no save, aplicar **efeito**:
   - Dano: rolar dados (considerar upcasting e scaling).
   - Cura: rolar dados.
   - Buffs/Debuffs: adicionar ao estado do alvo.
9. Gastar slot (se não truque): `caster.spellSlotsManager.useSlot(spellLevel)`.
10. Iniciar concentração (se aplicável): `caster.concentrationManager.startConcentration(spell, currentTurn)`.

## Validações Específicas

- **Componente Verbal**: Se o conjurador está sob efeito de *Silêncio* (magia ou condição) ou incapaz de falar, magias com V falham.
- **Componente Somático**: Se ambas as mãos estão ocupadas (sem talento Conjurador de Guerra), magias com S falham. Uma mão livre é suficiente.
- **Armadura**: Sem proficiência, todas as magias falham (mesmo sem S).
- **Ação bônus**: Se a magia foi lançada como ação bônus, o conjurador só pode lançar truques como ação padrão no mesmo turno (validar ao iniciar a ação padrão).
- **Concentração**: Se o conjurador já está concentrando e tenta lançar outra magia com concentração, a anterior termina automaticamente. O novo lançamento só ocorre se a anterior for rompida.

## Cálculos

- `DC = 8 + spellcastingAbilityModifier + proficiencyBonus`
- `spellAttackBonus = spellcastingAbilityModifier + proficiencyBonus`
- Dano escalado:
  - `per_slot_level`: dano base + (slotLevel - spellLevel) * diceIncrement
  - `per_character_level`: multiplicador de dados conforme nível (1,2,3,4 dados nos níveis 1-4,5-10,11-16,17+)
- Concentração quebra: `caster.makeConstitutionSave(dc)`. DC = max(10, floor(damage/2)). Se falhar, concentração perdida.

## Exemplo de Implementação Mínima (pseudocódigo)

```typescript
class SpellCastingEngine {
  castSpell(spell: Spell, caster: Character, target?: Character, slotLevel?: number): CastResult {
    // Validações
    if (!caster.canCast(spell)) return { success: false, reason: 'Spell not available' };
    if (!this.checkComponents(spell, caster)) return { success: false, reason: 'Components missing' };
    if (!caster.spellSlotsManager.canCast(slotLevel ?? spell.level)) return { success: false, reason: 'No slot' };
    if (!caster.isProficientWithArmor) return { success: false, reason: 'Armor proficiency' };

    // Quebra concentração anterior
    if (caster.concentrationManager.isConcentrating()) {
      caster.concentrationManager.breakConcentration();
    }

    // Calcula CD e bônus
    const dc = 8 + caster.spellcastingAbilityModifier + caster.proficiencyBonus;
    const attackBonus = caster.spellcastingAbilityModifier + caster.proficiencyBonus;

    // Executa efeito
    const result = this.applyEffect(spell, caster, target, slotLevel, dc, attackBonus);

    // Gasta slot
    if (spell.level > 0) caster.spellSlotsManager.useSlot(slotLevel ?? spell.level);

    // Inicia concentração
    if (spell.concentration) caster.concentrationManager.startConcentration(spell, caster.currentTurn);

    return { success: true, effect: result };
  }

  private applyEffect(spell: Spell, caster: Character, target: Character, slotLevel: number, dc: number, attackBonus: number): EffectResult {

      const attackRoll = caster.rollD20() + attackBonus;
      if (attackRoll >= target.armorClass) {
        // acerto: rolar dano
      }
    }

  }
}
```

## Observações Finais

- A lista de magias deve ser armazenada em uma base de dados (JSON/TypeScript) e carregada em tempo de execução.
- Para classes que preparam magias (Clérigo, Druida, Mago, Paladino), os slots preparados são escolhidos durante o descanso longo.
- Para classes que conhecem magias (Bardo, Feiticeiro, Bruxo, Patrulheiro, EK, AT), a lista é fixa e só muda ao subir de nível.
- Considere implementar um **SpellBook** (grimório) para o Mago, que contém todas as magias que ele conhece, e ele prepara um subconjunto diariamente.
- A integração com combate deve permitir que magias de dano em área afetem múltiplos alvos, com saves individuais.
